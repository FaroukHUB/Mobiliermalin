# Pages catégories produits — mobiliermalin.com

Toutes les pages catégories ont la même structure :
- Titre H1 + sous-titre court
- Bloc "Reconditionné" avec icône ✓ En stock + fourchette de prix TTC
- Liste de variantes / sous-types (textuelle, sans filtre actif sur l'ancien site)
- CTA "📧 Demander un devis" → mailto:mobiliermalin@gmail.com
- Galerie photos en bas
- Mention contact en pied de page

**Important** : sur l'ancien site, il n'y a **pas de panier ni de prix individuel calculé** — c'est un catalogue avec demande de devis par mail. Le **nouveau site doit le moderniser** avec vrai e-commerce.

## Constats stratégiques

- L'ancien site est **un catalogue, pas une boutique**. Tous les CTA mènent à un mailto, pas à un panier.
- **Très peu de produits "détaillés"** : seuls les 3 bureaux droits ont des fiches précises. Tout le reste est "à partir de X €" avec demande de devis.
- **Énorme opportunité** : le nouveau site doit créer **de vraies fiches produits unitaires** (chaque fauteuil, chaque table) → bcp plus de pages = bcp plus de SEO.
- **Galeries existantes** : pour les premières fiches, on peut récupérer les images de l'ancien site (URL `mobiliermalin.com/wp-content/uploads/...`).
- **Marques produits identifiées** : Majencia, Steelcase, Haworth, Herman Miller, Vitra.
- **Garantie** : "garantis" mentionné mais durée précisée seulement sur la home (6 mois).
